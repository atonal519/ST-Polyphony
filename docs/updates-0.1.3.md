# 百面相 0.1.3 内测版

- 在「设置 → 通用设置 → API 配置」编辑或新增连接时，展开「高级参数」即可填写排除参数、附加 JSON、超时秒数、失败重试次数、温度和流式开关。六项设置按预设单独保存，只在百面相生效。副模型跟随主模型时共用这套设置。
- 「听」在一次推演里区分亲历和转述。人物从别人那里听到消息时，按实际听到的部分记录。每条线的新进展、每个圈在「味」里的本轮说明都尽量控制在 100 字以内，超长内容仍可接收。
- 「设置 → 内容设置」新增「将听的公开线索带入正文」，默认关闭。开启后，生成正文时最多带入两条与当前人物有关的公开近况，聊天里不会增加楼层。
- 「嗅」的坊间传闻增加了熟人间的闲话、小道消息和捕风捉影的猜测。

已安装百面相的用户可以在酒馆扩展页更新。首次安装见[安装说明](https://github.com/atonal519/ST-Polyphony#安装内测版)。
