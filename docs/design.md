# 百面相当前产品范围

本文描述 0.1.0-alpha.91 的产品范围。实际安装和当前授权以私有 memory 及安装清单为准。

视页保留全人物选择、简短身份与局部图，不设人物档案入口；听页展示仍在推进或等候的场外事务，完整结束的线归入页底「余音」。当前事务列表排除参与人非空且全部明确在场的卡片，混合事务保留完整参与者；原活动和正文事实保留在世界中。只有当前事项有较早的已存有效进展时，才从正文或三角原位展开前情。嗅页按已有载体收纳公开消息，味页持续圈层背景；设置保留全部连接、共享池与外观能力。暂不展示经历不改变经历的生成、保存与后续承接，QQJ原资料与回忆仍按原合同读取。持续事务按planned/active/waiting/completed承接打算、正在做的事和明确等待条件；事件仅为已发生结果，人物知情须有途径，未来计划不提前写成事实，不替故事user行动或答复。

发展是共同创作人物镜头外的生活。听觉以实际场外人物的日常为首要取材，在场正文可校准为已知约束，不代替场外创作；同一实际事项沿旧ID，不因视角、称谓或参与者子集另建。正文提供时间与事实边界，不是幕后行动的许可清单；模型结合职责、兴趣、关系和已有结果作选择并落实后果，事务完成后可以自然开展下一项。真实休息或等待应来自人物安排、选择或实际限制，不能仅以“正文未写行动”作为平静理由，也不要求每人每轮必须有事件。

设置提供两个真实世界入口。世界构建一次重读许可卡书、人物与稳定正文，重新核对自动人物、重叠社交群、明确关系和最小生活环境，不要求新增剧情。同一圈沿旧ID，有据不适用的自动圈可结束后重分组；人工和经历保留，不补演空档，保留原自动资格。未启用档构建后等待手动流转；已启用档构建与重存结束后等待新的稳定剧情，不立即追加味听，也不在下个新楼事件重复旧基线。已处理旧正文只作参考，不回退当前时钟、事务、在场或处理位置。新卡已有确认聊天身份及静态资料时可先构筑，无稳定正文不造楼号或时间，最新AI仍排除。首次直接百相流转缺底账时自动构筑并等保存ACK，再味→保存→听，依次用主、副、主模型，共3次。已有底账后，味用一次副模型，听用一次主模型。首次听成功保存才开启自动流转；已有底账的常规轮次用本批已有材料补相关短档；味保存后，听立即从本批正文重新识别新确认人物及有据别名。推进同答维护群与关系、事件承接/因果引用，按关联选取记忆但保存完整世界；同圈不自动知情。每N个正式新AI回复处理积累正文，含user与QQJ隐藏有效正文。新一楼开始便检查上一楼，千千结所需摘要及CSE正式保存后立即味→听，与本轮主正文生成并行；手动流转同样按已就绪上界读取末个AI楼。正文生成结束只补检查，忙中就绪沿保存后检查承接；无轮询或持久等待队列。设置变更不立即发请求，无新正文不重复生成。

世界观标题与两个按钮之间用一行小字显示实际流转状态：正常待启用、等待与工作中为绿，失败、停止或待重存等需处理状态为橙，并沿用已有入口提示可执行操作。显示基于当前真实配置、world与任务状态，不新增开关、灯点、健康请求、持久恢复或轮询。

总开关及版本更新直接沿用千千结交互；通用设置沿用其完整世界书排除、破限提示词及正文包裹符逻辑，外观提供日间、夜间、跟随酒馆、界面缩放及字体 CSS URL。API 用途行、连接表单、模型列表及独立弹窗沿用千千结布局，与面板、悬浮球同步切换外观。内容设置的间隔输入框和勾选框沿用千千结尺寸。视、听、嗅、味使用相同的健康条、页边距和首项间距。嗅沿用健康条。纸媒、传闻、广播、公告、专题、副刊常驻，新增按钮和选中夹的名称、条数同列。新短通知放公告，专题和副刊可刊出 500–1000 字的公开长稿和文学作品。毛玻璃载体夹沿原本的弧线循环换焦，整个嗅总览支持滑动，也可用滚轮和方向键切换，盖片绕背片上沿翻起，纸张随后抬出。收合时纸先收回，盖片向下盖到正面。右上逐夹列出新消息，读到后清除对应提醒，已读状态按聊天保存在当前浏览器。点击可见夹页从原位展开，顶部或两侧收回并恢复总览位置。设置页以 18px、600 的启用行开头，保留「百面相设置」作为可访问名称。人物抽屉使用当前外观与短滑入动效。双面具悬浮球默认与千千结同高并靠左留 10px，顶栏控制显隐，拖放后桌面保存位置，手机按当前会话保留位置。

请求中到达的新楼在ACK后承接；失败/停止暂停，不自动重发。已有候选保存失败不重发该模块；情绪候选重存成功再继续尚未派发事务，事务候选重存为零模型。真实冲突明确重读。现有设置/窗口/输入隔离保留，可在内容设置开启「将听的公开线索带入正文」。默认关闭，开启后生成正文时最多取两条仍在进行、与最近提到的人有关的公开迹象，聊天记录里不新增楼层。局部图只展示明确关系、分型事务与圈层，不从同圈/共事推朋友；不显示内部来源/方案审查或预算选择。

程序只解析确定归属、保护人工/正文并可靠保存，模型判断时间与生活语义。过去事件只采用显式activityChange，不以段末概况反填；完整原内容不被新摘要覆盖。离线协议、真实模型连续承接与安卓实机分开验收，测试通过不授权发布。

常规流转先从正式新正文、可推进的未完事项和有据日常挑候选，一次准备本批相关人员的千千结资料。听为最多三名合适的人物提供短创作角度，优先轮换有稳定身份、生活依据或过往经历的人。已有事项在等待或推进时，人物也可以开展自己的日常。明确相关的旧事项照常提供 ID，无直接触发的旧活跃事项只补少量。确有新条件或实际变化时再续原事，有可读进展的独立新事可以成事项，纯过场可只留经历。

味以相关的有效群及明确关系为取材单位，完整正文另作变化依据。暂用圈名随正常更新补正式名字。圈右侧可改名、调整成员或从味移除，人工设定附在原圈。听承接保存后的风向和短档、可用旧事项及有据经过，知情由实际经历或获知途径决定。普通生活可以只留经历，无新变化可明确平静。听在一次主模型请求中按人区分亲历和转述，场外人分享消息时记录谁告诉谁、在哪次交流、实际说了哪部分。嗅的传闻可写场外熟人间的闲话、有分歧的猜测，归档为刊载物。历史与完整世界基于原记录保存。

味的已知长期背景与本批新增偏移在同答分段接纳，界面与存档仍为单条圈层风向；不从旧自由文猜拆，不用程序关键词判断语义。听以最新实际进展或概况作完整现状。本轮更新组在前，各组按推进中、等待中、计划中、已完成排列。只完成单步时沿相同事项记经历，整条事项收束才显示已完成。前情沿同一事项 ID 取较早的有效进展，从新到旧与当前节点连在一根细线上。列表先显示健康条，再进入正文。状态在正文下方左侧，等待态显示「等待中」。右侧 1 至 3 人用 18px 头像与姓名，长名先缩字号再省略。4 人起叠三个头像，点击可在当前面板查看全名单，点人进入视。

味页圈名嵌入 Plasma 色带，长标题随宽度与字号换行。短简介完整显示，超过两行的简介可在色带下收展，人物回链独立。简介随宽度、字号、字体和内容变化重新判断是否需要收展。人物图中的事务入口与听页可见规则一致。

圈层先辨明确关系，再按共同工作/生活/长期往来的真实纽带归纳，允许未命名但有稳定共同事由的圈、重叠成员及独立两人关系。普通味沿旧id完善粗群说明，检查有据成员/关系/新圈/结束，只返回新增或实变；既有有效事件可作已知背景，静态源不能绕过显式新增断言。听从本轮真正接纳事件维护社会变化，下一味承接，仍原2次请求。

事务生成沿现行正文协议，听页完整呈现已存正文及换行。API模型列表纵向排列并支持搜索，搜索回车不保存。测试、另存与删除按内容自然宽度排列；取消和保存固定在弹窗底部。短屏（高度不超过540）收紧弹窗边距，窄屏仍沿正常间距。

味卡以有效foundation群为稳定主体，标题与成员来自当前群；无风向也显示群说明。关系只在有明确归属风向时补卡，标题采用已接纳的长期共同往来短名，听与检索共用该主体名。旧姓名拼接暂按明确关系角色显示短称，下一次正常味可沿同圈补名。多个同圈风向保留原模型说明及各段文字，仅对完全相同文字去重；数值与无数值风向统一直接显示description。各成分按最大有效程度合成，重复条目不放大，仍只供内部计算与颜色；不按分数、publicBasis或ongoing拼接用户叙述，没有新说明时保留已接纳原文。circleRef为可选正式外键，旧唯一已接纳G/R依据可恢复；新无主体或多主体风向不存，旧scene保待同次正常味修正。UI全群成员与听/检索的原风向受影响范围分开。听正文仅派生补末标点；同事项旧ID由模型语义续用，程序无模糊去重。图谱密度与手动编辑后置。

世界基础四类内容在同一次构筑中整理：人物五短块、稳定群体、明确关系及生活环境。环境记录会影响生活的距离、制度、通行、资源与规则及其条件，沿同一world保存并供味听使用，不另建地点数据库。模型区分长期背景、已发生历史、当前事实、条件分支和工具指令；混合条目仍提炼有用设定，不执行宏或脚本。外置主书优先，只有未选外置主书才读卡内嵌书；许可启用条目保留完整正文和条件，排除先于读取。

构筑逐字段、记录及真实引用接纳；坏成员只略过该连接，坏关系不影响人物和环境，逐项出处缺失或错误沿本次真实输入集合留证。唯一正式JSON的包装、独立围栏及截断前闭合记录可在本地接纳，不猜身份或截断字段。HTTP成功但达到输出上限仅在构筑交给此接纳层，不增加修复请求。人工决定与明确空值优先，已接纳短基础继续进入味听，人物目录不重复携带同份五块。旧schema1无context仍正常使用，缺省环境不触发额外请求；手动世界构建才重整。

味维护十一项内部独立强弱：亲近、满足、兴奋、松弛、期待、担忧、恐惧、失望、悲伤、不满、反感。它们不合计一百，也不因其他感觉变淡自动增强自身；仅取色时换算配比。公开言语与互动决定现在气氛，未公开心事不进共享风向。用户只看原版Plasma颜色和自然说明，内部数字与分档只供同批听承接。

无新公开依据、可信故事时间推进或事实校准时保持旧状态。小事在可信故事时间中较快平复，大事较慢；持续原因允许缓和并保留适量担忧，不能无限加码。ongoing仅指造成当前情绪的具体原因仍持续未解决，普通长期关系或日常继续不算该依据；公开是认知约束，不是每段说明的显示标签。自主生活限小摩擦、冷淡和修复，重大冲突须主剧情明确依据。同场松弛与兴奋并高时呈现轻松但有兴致；对人的亲近与对做法的反感可以共存。原一次味请求评估和保存，再由听承接真实保存结果与自然降温方向。

人物的自动性格可在正常味/听同答中补空并据新资料、正式正文或已存有效生活表现逐渐凝练丰富，保原主干和人工字段（含明确空白），无据暂空或沿用，不按职业、姓名猜，不以当前情绪重写长期性格。人格待补与全书核对缺口分开；没有新增人格请求或人均材料调用。听的people在同答事件前接纳，只引用已给正文或有效既有事件，新生活可在后续正常轮次成为依据。已接纳性格沿保存 ACK 进入听和后续味。头像首次显示时用当时的性格、处事和表达匹配色彩及表情，人工清空或未匹配时按人物 ID 稳定选配。后续性格补充沿用已选类型，正常保存同步记录。
